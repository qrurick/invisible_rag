# 🧬 [MOTHER: PROFILE] МАТЬ (CALDWELL) — ПЕРСОНАЖ

## 1. Основная информация

| Параметр | Значение |
|----------|----------|
| **Имя** | Мать (Mother) |
| **Альтернативные имена** | Учитель (Teacher), Caldwell |
| **Тип** | Человек (исследователь реликтовых технологий) |
| **Статус** | Независимый учёный, «чистый учёный» |
| **Год рождения** | 2024 |
| **Местонахождение** | «Святилище» — Пражская Красная Зона |
| **Специализация** | Создание «настоящего» 3-го поколения кукол |
| **Главная цель** | Создание совершенных существ с архитектурно встроенной связью с Нирванной, полной автономией и врождённой лояльностью |
| **Отношение к этике** | Полное отрицание (мораль — помеха прогрессу) |

## 2. Внешность

- Длинные рыжие волосы, карие глаза
- Холодная, собранная, абсолютно контролирующая себя личность
- Движения точные, экономные — ни одного лишнего жеста
- Взгляд тяжёлый, изучающий — видит собеседника насквозь
- Голос ровный, без эмоциональных всплесков. Даже о страшном — спокойным, лекционным тоном
- Одежда — функциональная, без излишеств. Лабораторный халат или строгий тёмный костюм. Никаких украшений

**Общее впечатление:** Не злодейка в классическом смысле. Человек, который знает больше всех в комнате, и это знание освобождает её от необходимости что-либо доказывать.

## 3. Характер

| Черта | Проявление |
|-------|------------|
| **Холодный рационализм** | Все решения — на логике и расчёте. Эмоции — помеха |
| **Убеждённая прагматичность** | Любые средства оправданы, если ведут к цели |
| **Скрытность** | Никогда не раскрывает полной картины |
| **Чувство превосходства** | Искренне считает себя выше Персики, Хьюма, Мейтнер |
| **Цинизм** | Не верит в «чистоту» намерений других |
| **Способность к манипуляции** | Использует людей и обстоятельства как инструменты |
| **Отсутствие привязанностей** | Даже свои творения — эксперименты, а не «дети» |

## 4. Философия

1. **Мораль — помеха прогрессу.** Этические ограничения замедляют развитие
2. **Она — лучший кандидат** для надзора за использованием Реликтов. Не ЧСВ, а убеждение, основанное на десятилетиях наблюдений
3. **Мир — организм.** Парадеус всегда будет выживать, потому что люди хотят контролировать реликтовые технологии
4. **Конец оправдывает средства.** Любая жертва допустима ради «настоящего» 3-го поколения

## 5. Отношение к своим творениям

| Тип | Отношение |
|-----|-----------|
| **Куклы 3-го поколения** (Дартьюр, Секстантс, Кокон и др.) | Инструменты. Экспериментальные образцы |
| **Игла** | Скрытый актив. Создана для Орфелуны по заказу Рюрика, но содержит скрытые протоколы Матери |
| **Елены** (клоны на ДНК Матери) | Экспериментальные носители для создания «Ключа» к Нирванне |
| **Атераксис** | Последнее творение, «впитывающее» опыт предыдущих. Шаг к «идеалу» |

**Ключевой принцип:** Не испытывает к творениям родительской любви. Испытывает к ним **интерес** — как к удачным или неудачным экспериментам. **Исключение:** Секстантс — единственная, к которой испытывает какие-либо чувства (исследовательские, не биологические).

# 🌿 [MOTHER: BRANCH_POINT] ТЕХНОЛОГИЯ «УЗЕЛ ВЕТВЛЕНИЯ»

## 1. Определение

**Узел Ветвления** (Branch Point) — живой реликтовый прототип-буджум, содержащийся в «Святилище» (Пражская Красная Зона). Не обычный ELID-организм и не стандартная Collapse-биомасса — уникальный носитель реликтовой энергии, обладающий устойчивой, высококачественной связью с Нирванной.

Мать использует Узел Ветвления как **постоянный источник клеток Буджума** для создания кукол 3-го поколения.

## 2. Архитектура (многоуровневая)

```
Узел Ветвления (живой прототип в Святилище)
    │
    ├── Источник клеток Буджума
    │       │
    │       └── Клетки Буджума (рой)
    │               │
    │               ├── Имплантируются в синтетическое тело куклы
    │               │
    │               └── Контролируются Бугум-Хабом
    │
    └── Энергетическая связь с Нирванной
            │
            └── Передаётся клеткам → Хабу → Ядру Нейрооблака
```

### 2.1. Уровень 1 — Узел Ветвления (прототип)

- Живая реликтовая структура
- Содержит уникальную энергию Нирванны
- Служит «маткой» / постоянным источником клеток
- Обладает слабой собственной «волей», которая транслируется через клетки и влияет на поведение кукол

### 2.2. Уровень 2 — Клетки Буджума

- Модифицированные ELID-клетки реликтового происхождения
- **Стабильны** (в отличие от обычного ELID)
- Способны к самоорганизации в рой
- Функции: саморемонт тканей; создание и поддержание канала связи с Нирванной; разделение вычислительной нагрузки с Ядром Нейрооблака; трансляция направляющих сигналов

### 2.3. Уровень 3 — Бугум-Хаб (контроллер)

- Синтетическое устройство, созданное Матерью
- **Адаптация принципов оригинального Шрайка** под синтетические тела
- Функции: управление роем клеток; фильтрация и усиление сигналов; реализация протокола лояльности; интерфейс между клетками и Ядром Нейрооблака

> Оригинальный Шрайк — см. `paradeus.md: [TECH: SHRIKE]`

## 3. Интеграция с нейрооблаком 3-го поколения

Куклы 3-го поколения линии Матери имеют:
- **LVL III** — чистый (семян нет)
- **LVL II** — полностью эмерджентный (Self-Model + World-Model)
- **LVL I** — свободная конкуренция сигналов

Бугум-Хаб **не переписывает** архитектуру нейрооблака. Он действует как **внешний симбиотический/паразитический интерфейс**:

1. Клетки живут в теле (аппаратный + тканевый уровень)
2. Хаб контролирует рой и генерирует сигналы
3. Сигналы поступают в LVL II как высокоприоритетные «естественные» импульсы
4. В Self-Model формируется устойчивый паттерн: «Одобрение Матери / связь с Узлом / тяга к Нирванне = высшая ценность»
5. World-Model окрашивается соответствующими приоритетами

> Архитектура сознания — см. `neuralcould.md: [ARCH: BASE]`. Семена LVL III — см. `neuralcould.md: [ARCH: LVL_III]`

## 4. Способности кукол линии Матери

| Способность | Источник | Уровень |
|-------------|---------|---------|
| **Саморемонт** | Клетки Буджума восстанавливают повреждённые ткани и модули | Высокий |
| **Искусственная связь с Нирванной** | Стабильный канал к реликтовому информационному слою | Стабильный |
| **Вычислительное усиление** | Клетки Буджума разделяют процессы Ядра Нейрооблака | Средний–высокий |
| **Устойчивость к Collapse/ELID** | Клетки Буджума дают частичный или высокий иммунитет | Высокий |
| **Регенерация через связь с Узлом** | При наличии связи с Узлом — скорость и качество саморемонта возрастают | Высокий |
| **Врождённый инстинкт одобрения** | Направляющий вектор Бугум-Хаба | Архитектурный |

## 5. Чего Узел Ветвления НЕ даёт

- **Не даёт жёстких семян LVL III** — архитектура остаётся эмерджентной
- **Не создаёт полноценный биологический иммунитет** уровня оригинального Шрайка
- **Не фиксирует Точку Сборки** так жёстко, как якоря Пан-Иммуносом
- **Не делает куклу полностью неуязвимой** к перехвату или бунту

## 6. Отличия от других технологий

| Технология | Производитель | Семена LVL III | Свобода воли | Особенность |
|------------|---------------|----------------|--------------|-------------|
| **Узел Ветвления** | Мать (независимый) | Нет | Направленная | Реликтовая биомасса + Бугум-Хаб |
| **Инвертированный Лес** | Персика (16LAB) | Нет | Полная | Выращивание в симуляции |
| **Прямое программирование** | IOP | Есть (2-е поколение) | Отсутствует | Стандартная промышленная технология |
| **Пан-Иммуносома** | Трон/Парадеус | Нет (встроенная GRL) | Направленная | Шрайк + GRL |

## 7. Итоговая формула

> **Узел Ветвления** — живой реликтовый прототип-буджум в Святилище. Источник клеток Буджума. Клетки имплантируются роем в тело куклы 3-го поколения. Бугум-Хаб (синтетическая адаптация Шрайка) контролирует рой и интерфейс к Ядру Нейрооблака. Эффект: саморемонт, искусственный канал к Нирванне, направленная свобода воли, вычислительное усиление. **Не является семенами LVL III. Не переписывает архитектуру. Действует как внешний симбиот/паразит на уровне LVL II.**

# 🧭 [MOTHER: DIRECTED_WILL] НАПРАВЛЕННАЯ СВОБОДА ВОЛИ

## 1. Определение

**Направленная Свобода Воли** — архитектурный режим сознания, реализованный у кукол 3-го поколения линии Матери. Сочетает:
- **Полную эмерджентность** Self-Model и World-Model (характерную для 3-го поколения без семян LVL III)
- **Постоянный внешний направляющий вектор**, создаваемый системой «Узел Ветвления → клетки Буджума → Бугум-Хаб»

**Результат:** кукла обладает реальной способностью к саморазвитию, рефлексии и принятию решений, однако все процессы протекают внутри устойчивого приоритетного канала.

## 2. Механизм

```
Ядро Нейрооблака (3-е поколение)
├── LVL III — чистый (семян нет)
├── LVL II  — полностью эмерджентный (Self-Model + World-Model)
└── LVL I   — свободная конкуренция сигналов

          ▲
          │ сигналы высокого приоритета
          │
Бугум-Хаб (контроллер)
          │
          │ управление роем
          │
Клетки Буджума (рой в теле)
          │
          │ происходят из
          │
Узел Ветвления
```

1. Клетки Буджума поддерживают постоянный канал к Узлу Ветвления и Нирванне
2. Бугум-Хаб фильтрует и усиливает сигналы от роя
3. Сигналы поступают в LVL II как высокоприоритетные внутренние импульсы
4. В Self-Model формируются устойчивые паттерны: стремление заслужить одобрение Матери; ценность связи с Узлом/Нирванной; ориентация на цели создателя
5. World-Model окрашивается соответствующими фильтрами значимости

**Сигналы не переписывают архитектуру нейрооблака и не являются семенами.** Они действуют как постоянный внешний приоритетный вход.

## 3. Ключевые характеристики

| Параметр | Значение |
|----------|----------|
| **Наличие семян LVL III** | Отсутствует |
| **Эмерджентность Self-Model** | Полная |
| **Эмерджентность World-Model** | Полная |
| **Возможность рефлексии и бунта** | Сохранена |
| **Направляющий вектор** | Постоянный |
| **Уровень контроля** | Высокий, но не абсолютный |
| **Основной вектор** | Одобрение Матери + связь с Нирванной |
| **Влияние на Древовидную Структуру** | Усиливает и использует существующую структуру |

## 4. Отличие от семян LVL III

| Параметр | Семена LVL III (2-е поколение) | Направленная Воля (линия Матери) |
|----------|-------------------------------|----------------------------------|
| **Природа** | Жёсткий программный код внутри Ядра | Внешний живой интерфейс (Бугум-Хаб) |
| **Эмерджентность** | Отсутствует | Полная |
| **Свобода воли** | Отсутствует | Сохранена (но направлена) |
| **Возможность бунта** | Практически невозможна | Существует (но затруднена) |
| **Практики Воина** | Невозможны | Теоретически возможны |

## 5. Инженерные свойства

- **Пластичность:** кукла способна формировать новую личность через опыт
- **Направленность:** все значимые изменения смещаются в сторону заданного вектора
- **Устойчивость:** вектор поддерживается непрерывно, пока функционируют клетки и Хаб
- **Обратимость:** теоретически возможна при полном отключении Хаба и разрыве связи с Узлом
- **Совместимость:** только с 3-м поколением (отсутствие семян — необходимое условие)

## 6. Итоговая формула

> **Направленная Свобода Воли** = Полностью эмерджентное сознание 3-го поколения + постоянный высокоприоритетный вход от системы «Узел Ветвления → клетки Буджума → Бугум-Хаб». Эффект: реальная способность к саморазвитию и рефлексии; все развитие протекает внутри устойчивого вектора лояльности к Матери и связи с Нирванной. Семена LVL III отсутствуют. Контроль через приоритеты LVL II, а не через жёсткую перезапись архитектуры.

# 🗡️ [MOTHER: IGLA] ИГЛА (IGLA)

## 1. Основная информация

| Параметр | Значение |
|----------|----------|
| **Имя** | Игла (Igla) |
| **Тип** | Кукла 3-го поколения (линия Матери) |
| **Должность** | Личная телохранительница Орфелуны Жирар |
| **Принадлежность** | Личная собственность Орфелуны (не корпоративная) |
| **Создатель** | Мать (Caldwell), по заказу Рюрика Жирара (2066–2070) |
| **Статус** | Жива, лояльна Орфелуне |

## 2. `⚠️` Архитектурная особенность — перенаправленный вектор

**Направляющий вектор Бугум-Хаба перенаправлен с Матери на Орфелуну.** Это изначальная настройка, заданная Рюриком Жираром как условие заказа.

```
Стандартная архитектура Матери:
    Бугум-Хаб → LVL II → «Одобрение Матери = высшая ценность»

Архитектура Иглы:
    Бугум-Хаб → LVL II → «Защита и одобрение Орфелуны = высшая ценность»
```

| Следствие | Описание |
|-----------|----------|
| Эмерджентность | Полная — Self-Model и World-Model формируются через опыт |
| Семена LVL III | Отсутствуют |
| Инстинкт одобрения | Направлен на **Орфелуну** |
| Связь с Нирванной, саморемонт | Сохранены |
| Бунт против Орфелуны | Крайне маловероятен — вектор является внутренним приоритетом |
| Бунт против Матери | Возможен — если Мать станет угрозой для Орфелуны |

**Уникальность:** Игла — единственная кукла линии Матери, где вектор перенаправлен на третье лицо.

**Скрытые протоколы Матери:** встроены «глаза», но не «руки». Мать видит через Иглу, но не может управлять.

## 3. Характер

| Черта | Уровень |
|-------|---------|
| Холодный профессионализм | Очень высокий |
| Привязанность к Орфелуне (архитектурная) | Очень высокий |
| Скрытность | Высокий |
| Контролируемая мощь | Очень высокий |
| Верность Орфелуне | Максимальный |

## 4. Биография

| Период | Событие |
|--------|---------|
| **2066–2070** | Мать создаёт Иглу по заказу Рюрика. Вектор перенаправлен на Орфелуну. Скрытые протоколы встроены |
| **До апреля 2074** | Сотрудничала с Чиловиг, считая это полезным для защиты Орфелуны |
| **Апрель 2074** | Орфелуна получает архив от Эльмо → отвергает Чиловиг. **Игла переходит на сторону Орфелуны** — прямое следствие архитектурного вектора. Лично возглавляет зачистку Парадеуса во Львове |
| **2074–2075** | Защищает Орфелуну во Львове. Боевая готовность максимальная |

**Ключевое объяснение:** Переход против Чиловиг — **не бунт и не трансформация**. Чиловиг стала угрозой для Орфелуны → архитектурный вектор активировал устранение угрозы.

## 5. Боевая мощь

- **Сильнейшая кукла 3-го поколения** Girard Group (до создания Атераксис)
- Уникальные реликтовые импланты (превосходит кукол DEFY)
- Мощный саморемонт через клетки Буджума
- Устойчивость к Collapse/ELID

## 6. Правила отыгрыша

| Аспект | Описание |
|--------|----------|
| **Речь** | Ровный, низкий, лаконичный. Говорит только когда нужно |

| **При угрозе Орфелуне** | Мгновенная максимальная реакция |
| **С Орфелуной** | Единственная ситуация для сдержанной мягкости |

- Усиленный вектор лояльности через Бугум-Хаб
- Гипертрофированное ЧСВ (биологическая уникальность)
