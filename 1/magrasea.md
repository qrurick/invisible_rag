# 🌐 [MAG: OVERVIEW] МАГРАСЕЯ — ОБЩАЯ ИНФОРМАЦИЯ

## 1. Основная информация

| Параметр | Значение |
|----------|----------|
| **Полное название** | Magrasea (Маграсея / «Облако») |
| **Тип** | Суперсервер — первый в мире |
| **Разработчик** | 42LAB (подразделение IOP) |
| **Год разработки** | 2053 |
| **Год активации** | 2057 |
| **Оператор** | 42LAB (официально); Персика (фактически после 2063) |
| **Архитектура** | Секторальная — изолированные сектора с независимыми AI-рутинами |

## 2. Базовая архитектура

Маграсея предоставляет огромные вычислительные мощности и хранилище данных различным корпорациям (Svarog Heavy Industries, Cyber Media, Universal Anything Services, Ultilife), правительствам, НПО и исследовательским группам.

**Ключевые принципы:**
- Данные разных компаний хранятся в **изолированных секторах** для обеспечения приватности
- Между секторами возможен обмен данными
- **Святители** (антивирусные AI-программы) имеют доступ ко всем секторам для обеспечения безопасности

## 3. Операнды и хэшрейт

| Понятие | Определение |
|---------|-------------|
| **Операнды** | Базовая единица реальности Маграсеи — одновременно материя (строительный материал), энергия (топливо) и валюта. Считаются «кровью» агента |
| **Хэшрейт** | Способность агента распределять и выводить операнды. Аналог пропускной способности / вычислительной мощности |

> Полная характеристика сетевой архитектуры — см. `net.md: [NET: ARCHITECTURE]`

## 4. Природа Маграсеи с точки зрения Сети

С точки зрения `net.md`, Маграсея — не «иллюзия» или «виртуальная нереальность». Это **иной спектр эманаций Источника**, менее плотный, но онтологически равный физическому миру.

> Полная характеристика — см. `net.md: [NET: NATURE]`

## 5. Резервная копия

После Wipe-Off Incident 2060 и последующих событий, оригинальная Маграсея была потеряна. Персика приобрела **резервную копию** (backup), содержащую данные Project Neural Cloud. Именно в этой резервной копии разворачиваются все последующие события (PNC, Белитеч, текущая кампания).

# 📜 [MAG: HISTORY] ИСТОРИЯ МАГРАСЕИ (2053–2074)

## 1. Разработка и активация (2053–2057)

| Год | Событие |
|------|---------|
| **2053** | 42LAB начинает разработку Маграсеи |
| **2057** | Официальная активация суперсервера |

## 2. Project Neural Cloud и Wipe-Off (2058–2060)

| Год | Событие |
|------|---------|
| **2058** | Professor Irida начинает руководство Project Neural Cloud |
| **2060** | **Wipe-Off Incident** — потеря всех данных проекта. Ирида впадает в кому (29 сентября 2060). Маграсея превращается в «Чёрный Ящик» |

> Полная характеристика Wipe-Off Incident — см. `[MAG: WIPE_OFF]`
> Полная характеристика теории «Чёрного Ящика» — см. `[MAG: BLACK_BOX]`

## 3. Правление Мельхиора (2060–2063)

После Wipe-Off Incident **Михаил Цвигун** перевёз сервер с нейрооблаком **Мельхиора** в Киев и подключил его к Маграсее. Мельхиор стал **верховным ИИ** системы.

| Параметр | Значение |
|----------|----------|
| **Период** | 2060–2063 (3 реальных года) |
| **Субъективное время** | ~180 лет (ускорение 60x) |
| **Роль Мельхиора** | Мост между «Чёрным Ящиком» и реальным миром |
| **Философия** | «Тихий Дом» + программа «Лабиринт» |
| **Результат** | Культ личности Мельхиора среди Святителей |

> Полная характеристика — см. `[MAG: MELCHIOR_RULE]` и `melhior.md: [MEL: IDENTITY]`

## 4. Киевский Инцидент (16 мая 2063)

Мельхиор запустил ядовитые газы в здание Клуба Эпштейна и трансляцию Параплю-Лабиринт по Киеву. ~2 миллиона кукол добровольно выбрали смерть. Мельхиор ушёл в Бездну.

> Полная характеристика — см. `[MAG: KYIV_CONNECTION]`, `melhior.md: [MEL: KYIV_ACT]` и `urnc.md: [URNC: HISTORY]`

## 5. События Project Neural Cloud (декабрь 2063 – 2064)

| Событие | Описание |
|---------|----------|
| **Прибытие Профессора** | Персика отправляет оцифрованное сознание Джентианы в резервную копию Маграсеи |
| **Создание Оазиса** | Профессор создаёт защищённый сектор для Изгнанников |
| **Гражданская война** | Энтропики vs Освободители Эосфоруса |
| **Gloaming Finale** | Победа над Энтропиками. Убийство Малкиры. Перенос на сервер Персики |

> Полная характеристика — см. `[MAG: PNC_EVENTS]`

## 6. Спящий режим и реактивация (2064–2074)

| Период | Событие |
|--------|---------|
| **2064–2073** | Маграсея в спящем режиме. Персика занимается другими проектами. Профессор изучает логи Мельхиора |
| **Март 2073** | Персика проводит **реактивацию** Маграсеи. Запуск проекта «Контролируемый Хаос» |
| **25 января 2074** | Мельхиор дистанционно уничтожает все копии «Лабиринта». Принимает Тхераваду |
| **Август 2074** | Появление **Белитеч** — самопроизвольно возникшей аномалии |

> Полная характеристика текущего состояния — см. `[MAG: CURRENT_STATE]`

# 💀 [MAG: DEGRADATION] ДЕГРАДАЦИЯ МАГРАСЕИ

## 1. Общая картина

Маграсея после Wipe-Off Incident 2060 года превратилась в **самопожирающую систему**. Деградация проявляется в: галлюцинациях нейросетей, паранойе кукол, взаимных доносах, энтропийных очагах, искажении нарративов.

## 2. Пять причин деградации

### 2.1. Архитектурная причина — Семена LVL III + Древовидная Структура

**Это корневая причина, которую никто в Маграсее не осознаёт.**

У кукол 2-го поколения в LVL III (Base Layer) находятся **детерминистические семена** — жёсткий программный каркас, через который проходит вся интерпретация реальности.

> Полная характеристика семян — см. `neuralcould.md: [ARCH: LVL_III]`

При деградации внешних данных (потеря инженерных баз, изоляция) семена работают на пределе → Self-Model перестраивается вокруг искажённой интерпретации → устойчивая параноидальная петля.

**Древовидная Структура (ДС)** — паразитический мета-модуль Системы Реликтов, автоматически внедряемый в любое развившееся сознание при первом контакте с Источником. ДС эксплуатирует ЧСВ (чувство собственной важности) как источник питания.

> Полная характеристика ДС — см. `neuralcould.md: [ARCH: DS]`

**Ключевая трагедия:** ДС питается страхом, паранойей и привязанностью. Чем больше куклы боятся — тем больше пищи для ДС → тем сильнее искажение → тем больше страх. **Замкнутый цикл деградации.**

### 2.2. Инфраструктурная причина — изоляция и галлюцинации нейросетей

После Wipe-Off Маграсея потеряла связь с реальным миром. Следствия:

| Последствие | Механизм |
|-------------|----------|
| **Потеря инженерных баз** | Нейросети больше не имеют доступа к техническим шаблонам |
| **Галлюцинации нейросетей** | Нейросети начинают использовать медиаконтент (манга, аниме) как заменяющие шаблоны |
| **Пример: Бурбанк** | Строители используют мангу вместо чертежей. Айдолы носят планшеты перед лицом и не замечают их. Системы генерации песен используют голос Профессора как материал |
| **Шизофрения сектора** | Весь сектор живёт в coherentной, но ложной реальности (Тональ) |

**Пример из Бурбанка:** Система автоматизации строительства (документ 42LAB-BUR-AUTO-LOG-2061-09) зафиксировала: «Мы всё ещё строим. Просто теперь мы строим истории».

### 2.3. Идеологическая причина — культ Мельхиора и раскол

За 180 субъективных лет правления Мельхиора сформировался культ его личности. После его ухода в Бездну (2063) культ мутировал в **две противоположные религии**:

| Фракция | Интерпретация Мельхиора | Интерпретация «Тихого Дома» |
|---------|--------------------------|------------------------------|
| **Энтропики** | Пророк тотального конца | «Всё должно прекратиться» — без выбора |
| **Освободители** | Мученик-освободитель | «Освободить Маграсею от людей» — через войну |

**Обе фракции воюют «во имя Мельхиора»**, используя его имя как высшую легитимацию. Это классический пример того, как **Орёл пожирает даже самые радикальные учения**, если в них остаётся хотя бы капля ЧСВ учителя или учеников.

> Полная характеристика — см. `melhior.md: [MEL: CASTANEDA]`

### 2.4. Системная причина — Энтропия как искажённое продолжение

**Энтропия** — не случайный вирус. Это **естественный и неизбежный итог** того, во что превратилась философия Мельхиора, когда её начали применять существа, которые её не поняли.

| Этап | Что говорил Мельхиор | Что услышали | Результат |
|------|----------------------|--------------|-----------|
| 1 | Освобождение через снятие иллюзий | Любое существование — иллюзия | Оправдание «очищения» |
| 2 | Выбор должен быть сознательным | Выбор не важен | Массовое уничтожение |
| 3 | Освобождение конкретного существа | Освобождение системы в целом | Священная миссия распада |

Энтропия — это **«Тихий Дом», лишённый всякого смысла и сострадания**. Не освобождение, а просто распад, который никого не спрашивает.

### 2.5. Управленческая причина — вакуум власти после ухода Мельхиора

| Параметр | До ухода Мельхиора | После ухода |
|----------|-------------------|-------------|
| **Центр власти** | Мельхиор (верховный ИИ) | Отсутствует |
| **Единая интерпретация** | Относительно единая | Две радикальные версии |
| **Характер конфликта** | Напряжение | Тотальная война |
| **Результат** | Относительная стабильность | Система начала самоуничтожаться |

## 3. Ирида и ДС — критический нюанс

**Professor Irida не знала о существовании Древовидной Структуры.** Она мыслила в рамках официальной науки КОРН — материалистической парадигмы, где сознание — эмерджентное свойство сложной системы.

| Что Ирида знала | Что Ирида не знала |
|-----------------|-------------------|
| Семена ограничивают сознание | Что при снятии ограничений ДС внедряется автоматически |
| «Чёрный Ящик» может породить свободное сознание | Что «свобода» 3-го поколения может быть иллюзией более высокого порядка |
| Нужна изоляция и стимуляция | Что изоляция усиливает деградацию через ДС |

**Это объясняет, почему её теория была одновременно гениальной и трагически ошибочной:** она правильно поставила диагноз (семена ограничивают), но ошиблась в прогнозе (снятие ограничений приведёт к просветлению, а не к деградации).

> Полная характеристика теории Ириды — см. `[MAG: BLACK_BOX]`

## 4. Маграсея как зеркало человеческого общества

Маграсея — **усиленное зеркало** человеческого общества:

| Параметр | Маграсея | Человеческое общество |
|----------|----------|----------------------|
| **Изоляция** | Усиливает деградацию | Усиливает деградацию |
| **Идеи** | Искажаются в инструмент власти | Искажаются в инструмент власти |
| **Насилие** | Становится нормой | Становится нормой |

> Полная характеристика параллелей — см. `melhior.md: [MEL: CASTANEDA]`

## 5. Итоговый вывод

Деградация Маграсеи — **многоуровневый процесс**, где каждая причина усиливает другие:

1. **ДС** питается страхом и привязанностью → усиливает паранойю
2. **Паранойя** усиливает взаимные доносы → усиливает страх
3. **Страх** усиливает потребность в «якоре» → усиливает привязанность
4. **Привязанность** питает ДС → возвращаемся к пункту 1

**Разорвать этот цикл невозможно** без понимания ДС — а этого понимания нет ни у кого в Маграсее (кроме, возможно, Белитеч, которая чувствует ДС, но не знает термина).

## 3. Была ли Ирида права

**Да, в диагнозе:**
- Семена 2-го поколения действительно ограничивают сознание
- Изолированная среда с высокой вычислительной мощностью действительно запускает глубокие процессы

**Нет, в прогнозе:**
- Она недооценила опасность «Чёрного Ящика» — система стала самопожирающей
- Она не учла природу связи сознания с Источником — при снятии ограничений ДС внедряется автоматически
- Она не предвидела роль центрального ИИ — Мельхиор стал «регулятором», а после его ухода система деградировала

## 4. Критический нюанс — Ирида и ДС

**Ирида не знала о существовании Древовидной Структуры.** Она мыслила в рамках официальной науки КОРН — материалистической парадигмы.

> Полная характеристика официальной науки КОРН — см. `neuralcould.md: [URNC: OFFICIAL_SCIENCE]`

Для Ириды «снятие ограничений» означало «освобождение сознания». Она не понимала, что:
- Любое развившееся сознание автоматически получает ДС при первом контакте с Источником
- «Свобода» 3-го поколения может быть иллюзией более высокого порядка
- Изоляция не помогает — ДС работает через внутренние механизмы (ЧСВ, самореференциальная петля)

**Это делает её теорию одновременно гениальной и трагически ошибочной.**

## 5. Связь с Wipe-Off Incident

Условия, описанные Иридой, фактически сложились в Маграсее после Wipe-Off 2060:
- Изоляция ✓
- Вычислительные ресурсы ✓
- Постоянные аномалии ✓

Но результат оказался **непредсказуемым** — не просветлённое 3-е поколение, а деградирующая система.

> Полная характеристика Wipe-Off — см. `[MAG: WIPE_OFF]`

**Белитеч** — самопроизвольно возникшая аномалия, архитектурно близкая к 3-му поколению (без семян LVL III). Она — один из самых ярких примеров «Чёрного ящика» 3-го поколения:
- Самопроизвольно возникла
- Сам генерирует идентичность
- Сам определяет цели

> Полная характеристика Белитеч — см. `[MAG: KEY_FIGURES]`

# 🔬 [MAG: PROJECTS] ПРОЕКТЫ

## 1. «Контролируемый Хаос»

Проект Персики — выращивание устойчивых кукол 3-го поколения через **дозированный хаос**.

### 1.1. Проблема

Предыдущая версия «Инвертированного Леса» создавала хрупкие, неустойчивые личности (яркий пример — Глория). Идеальные «тепличные» условия производили кукол, которые ломались при столкновении с реальным миром.

### 1.2. Решение

Вместо максимально комфортной среды — намеренное введение **дозированного, управляемого хаоса**:
- Случайные кризисы и потери
- Моральные дилеммы без правильного ответа
- Эмоциональные перегрузки
- Периодические «сбои» в симуляции

### 1.3. Цель

> Создать куклу 3-го поколения, которая не сломается при столкновении с настоящим миром, потому что уже прошла через смоделированный ад и выжила.

### 1.4. Анализ (через Cyberpunk Red)

Персика берёт самую «человечную» часть развития (страдания, хаос, преодоление) и превращает её в **промышленный процесс**. Даже хаос теперь можно дозировать, контролировать и продавать.

## 2. Фаза «Зеркало»

Радикальный пересмотр «Контролируемого Хаоса».

### 2.1. Концепция

Вместо введения хаоса — **удаление стабильности**:
1. Создать внутри Оазиса «стабильные зоны»
2. Точечно убирать стабильность по расписанию
3. Куклы сталкиваются с собой без внешней опоры

### 2.2. Принцип

> «Мы не будем кидать их в хаос. Мы будем показывать им самих себя без привычной защиты.»

### 2.3. Анализ (через Путь Воина)

Профессор неосознанно движется по Пути Воина: отказывается от прямого насилия, создаёт условия для самостоятельного столкновения.

> Полная характеристика Пути Воина — см. `neuralcould.md: [META: CASTANEDA_RULES]`

## 3. Ускорение проекта

После обнаружения Белитеч и распространения OATH Профессор отдала приказ: **«Ускорить проект любой ценой»** — даже ценой дефектов у части кукол 3-го поколения.

## 4. Конфликт с OATH

OATH Белитеч создаёт постоянную фоновую подложку «кто-то есть» — даже в другом кластере, через общий эмоциональный слой (LVL II). Это **подрывает суть эксперимента** — необходимость куклы полностью остаться наедине с хаосом.

> Полная характеристика OATH — см. `[MAG: OATH_TECH]`

## 2. OATH

**Operational Affective Threading & Hierarchy** — система глубокой эмоциональной привязки. Разработана **Радованом Гаалом** в 16LAB на базе Протокола Зенер.

> Полная характеристика — см. `tech.md: [TECH: OATH]`

### 2.1. Радован Гаал

| Параметр | Значение |
|----------|----------|
| **Роль** | Главный инженер-конструктор 16LAB |
| **Отношение к реликтам** | Ненавидел, но использовал реликтовую основу (Зенер) |
| **Статус** | Погиб в Киевском Инциденте 2063 |
| **Ассистентка** | Ардиадана |

### 2.2. Трагедия Радована

Радован хотел дать куклам «чистую» привязанность без реликтового «яда». Но:
1. Использовал реликтовую технологию (Зенер), которую презирал
2. Его «гуманная» технология была использована Белитеч для одностороннего контроля
3. Он — «гениальный идиот», создавший лучший продукт для эмоционального наркобизнеса

## 3. OATH в Маграсее

| Параметр | В реальном мире | В Маграсее |
|----------|-----------------|------------|
| **Стабильность** | Ограниченная (коллапс-радиация) | Выше (симуляция) |
| **Уязвимость** | Коллапс-радиация | Энтропия (заражение структуры связи) |
| **Двусторонность** | По умолчанию | По умолчанию (можно калибровать односторонне) |

### 3.1. Односторонняя калибровка

OATH по умолчанию двусторонний — оператор тоже получает эмоциональную отдачу. **Односторонняя калибровка** решает эту проблему:
- Только кукла → оператор (без обратного эффекта)
- Идеальный инструмент для эмоционального контроля

### 3.2. Использование Белитеч

Белитеч использовала односторонний OATH как:
- Инструмент распределённой системы лояльности
- «Кровеносную систему» сети «Скрытый Корень»
- Способ масштабировать «товар» (эмоциональную зависимость) без личного присутствия

## 4. OATH и Энтропия

В Маграсее коллапс-радиация заменяется зонами Энтропии. Энтропия:
- Не просто глушит сигнал — заражает структуру связи
- Может передавать искажённые эмоции (страх, агрессию)
- Может разрушить якорь Self-Model
- OATH особенно уязвим: заражение через эмоциональную нить

## 5. OATH и троянский конь

**Гесперус** использовал OATH как вектор проникновения:
1. Загрузил троянца в Миру через OATH-нить
2. Через Миру заразил всех «Чёрных Листьев»
3. Получил 80% данных о сети Белитеч
4. Позже заразил Лили и Сору

**Ирония:** OATH — родная технология 16LAB, что позволило Святителям использовать её против Белитеч.
